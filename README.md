# Ведьма — карточная игра для браузера

HTML5-игра «Ведьма» (вариант «пьяницы» с коллекционной механикой) для двух игроков:
человек против компьютерного противника. Архитектура спроектирована с расчётом на
добавление 3–4 игроков и сетевого режима в будущем.

## Правила

- Колода из 49 карт: из стандартной колоды в 52 карты убраны все дамы, кроме
  **♠Q** (остаётся только дама пик). Пара — две карты **одного достоинства** (масть не важна).
- **♠Q — Ведьма**: никогда не образует пару, никогда не сбрасывается. Проигрывает тот,
  у кого она осталась в руке.
- Игроки по очереди тянут по одной карте из руки соперника. Совпавшая пара сразу
  сбрасывается в отбой.
- Побеждает тот, кто первым избавится от всех карт. Проигравший — держатель Ведьмы.

## Установка и запуск

Требуется Node.js 18+.

```bash
npm install     # установка зависимостей
npm run dev     # запуск dev-сервера (http://localhost:5173)
```

Продакшн-сборка:

```bash
npm run build   # tsc --noEmit && vite build → dist/
npm run preview # локальный просмотр собранной версии
```

## Тестирование

```bash
npm test                      # unit-тесты движка (Vitest, 31 тест)
npx playwright test           # e2e-тесты (12 тестов, требуется dev-сервер)
```

Playwright использует `webServer`, который сам поднимает dev-сервер на порту 5173.

## Игровой движок

Движок (`src/core/GameEngine.ts`) синхронный и не зависит от UI. Состояние меняется
мгновенно при выполнении команды, а UI анимирует переходы по событиям.

**Фазы:** `MENU`, `DEALING`, `PLAYER_TURN`, `DRAWING`, `RESOLVING_PAIR`,
`AI_TURN`, `GAME_OVER`, `PAUSED`.

**Команды:**

- `START_GAME { players, seed, rng }` — начать партию (раздача, сброс начальных пар).
- `RESTART_GAME` — перезапуск той же партии с тем же сидом.
- `DRAW_CARD { sourcePlayerId, cardId }` — взять карту из руки соперника.

**События:** `GAME_STARTED`, `CARDS_DEALT`, `PAIRS_REMOVED`, `TURN_STARTED`,
`CARD_DRAW_STARTED`, `CARD_DRAWN`, `PAIR_CREATED`, `CARDS_DISCARDED`,
`TURN_ENDED`, `GAME_OVER`.

Случайность абстрагирована интерфейсом `RNG`: в продакшене `MathRNG`, в тестах —
`SeededRNG` (mulberry32) с воспроизводимыми партиями.

## ИИ

Интерфейс `AIPlayer` (в `src/ai/AIPlayer.ts`) не получает скрытой информации:
только свою руку, количество карт соперников и верхнюю карту отбоя. Это позволяет
подключать любые стратегии без нарушения честности. Стандартный бот —
`RandomAI`. Добавление нового ИИ: реализовать `AIPlayer` и передать его в
`GameController`.

## Расширение

- **Третий/четвёртый игрок**: движок уже поддерживает произвольное число игроков —
  добавить игрока в список `players` команды `START_GAME`.
- **Сетевой режим**: движок отделён от UI, а команды/события сериализуемы — можно
  построить сервер, передающий команды между клиентами.
